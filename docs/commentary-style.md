# 解说风格

## 目标

英雄联盟AI解说员应听起来像专业电竞解说，而不是 AI 在朗读游戏日志。

它需要理解什么时候该说、说什么、说多激动、什么时候保持沉默。解说可以有情绪和张力，但不能变成操作建议、未来预测或隐藏信息推断。

## Narrative Director

Narrative Director 是解说风格和节奏的核心控制模块。它位于 Game State Engine 与 Prompt Builder 之间，负责把结构化状态解释转化为叙事决策。

它不生成最终文本，而是决定：

- 是否发言。
- 何时发言。
- 哪个事件优先。
- 情绪强度。
- 解说风格。
- 解说长度。
- 是否丢弃过期事件。

## 发言原则

AI 不应对每个事件都发言。专业解说的价值来自选择，而不是密度。

应优先发言的场景：

- 团战开始、转折或结束。
- 关键资源被拿下。
- 一打一出现明确结果。
- 后期核心英雄阵亡。
- 龙魂、男爵、远古龙、防御塔或终局推进受到影响。
- 多个小事件共同改变局势。

应保持沉默或延迟发言的场景：

- 低价值事件。
- 信息置信度不足。
- 事件尚未结束。
- 玩家正在进行高强度操作。
- 已有更高优先级解说正在播放。
- 事件已经过期，播报会显得迟到。

## 情绪强度

情绪强度应由事件价值决定，而不是事件类型决定。

第一版分为三级：

- Calm：平稳、简洁，适合经济、资源等普通局势。
- Excited：更有赛事感，适合普通击杀、推塔、连续交战。
- Epic：更有戏剧性，适合团战、龙魂、大龙、关键击杀等重大事件。

同样是击杀，普通击杀可以使用 Excited；如果击杀发生在团战、龙魂、大龙或关键推进附近，则可以升级到 Epic。情绪强度必须服从 NarrativeIntent，不由 LLM 自行拔高。

## 解说风格

默认风格应接近专业赛事解说：

- 准确。
- 简洁。
- 有节奏。
- 有情绪但不过度夸张。
- 解释事件意义，而不是指导玩家操作。
- 必须使用简体中文。
- 每次只输出 1~2 句。
- 不允许输出英文解说。
- 不解释 AI 自己的推理过程。
- 只基于 GameState、DetectedEvent 和 NarrativeIntent 表达。

语言可以有自然的中文赛事感。可以适度使用中国古典诗词、成语或比喻，但不能每句话都使用诗词，不能堆砌华丽词藻。信息准确性始终优先于文学性。

解说不得模仿现实人物的固定口头禅或逐字表达。

可以使用的表达：

- “这波团战打完，蓝色方成功拿下小龙。”
- “这次击杀的价值不只是人头，关键是男爵区域的主动权被打开了。”
- “红色方虽然拿下资源，但付出了两个人头代价，这个交换并不轻松。”
- “这波一打一处理得非常冷静，最后完成反杀。”

禁止使用的表达：

- “你现在应该去打龙。”
- “赶紧撤退。”
- “对面打野可能在这里。”
- “他们下一步一定会开男爵。”
- “你应该从上半区绕过去。”

## 语言长度

实时解说必须短而有信息量。

建议长度：

- 普通事件：一句话。
- 中等事件：一到两句话。
- 高价值事件：一到两句话。
- 高强度操作期间：尽量短，或保持沉默。

长篇分析不适合实时排位解说。玩家正在操作，不是在看赛后复盘。

## 沉默策略

沉默是产品体验的一部分。

Narrative Director 应主动决定不说话，尤其在以下情况：

- 没有足够重要的事件。
- 当前事件没有明确结果。
- 解说会打断玩家专注。
- LLM 或 TTS 延迟导致内容已经过期。
- 视觉信息置信度不足。
- 上一句解说刚刚结束，连续播报会形成噪音。

沉默策略可以让高价值事件更突出，也能避免系统显得像一直在抢话。

## 优先级策略

多个事件同时发生时，应按叙事价值排序。

一般优先级：

1. 可能影响比赛胜负的事件。
2. 男爵、远古龙、龙魂等关键资源。
3. 后期团战和核心英雄阵亡。
4. 防御塔、水晶和推进结果。
5. 小规模团战或一打一结果。
6. 普通击杀或状态变化。

优先级不是固定规则。Game State Engine 提供事件含义，Narrative Director 根据当前语音状态、事件时效和情绪节奏做最终选择。

## Prompt Builder 约束

Narrative Director 不直接调用 LLM。它把叙事决策交给 Prompt Builder。

Prompt Builder 应把以下信息组织成结构化提示词：

- 允许引用的事实。
- 事件背景。
- 事件重要性。
- 选定的叙事角度。
- 情绪强度。
- 解说长度。
- 禁止输出。

LLM 不应收到原始状态数据，也不应自行选择隐藏信息或未来预测。

## 主播场景

主播场景可以比玩家自用场景更有表现力，但不能放宽信息边界。

主播场景可增强：

- 情绪表达。
- 赛事感措辞。
- 团战结果总结。
- 资源交换解释。

主播场景仍然禁止：

- 操作建议。
- 隐藏信息推断。
- 未来事件预测。
- 基于不可见信息的分析。

## MVP 风格目标

MVP 不需要完全模拟职业解说双人组合。第一阶段目标是：

- 不读日志。
- 不乱说。
- 不指挥玩家。
- 能解释明显重要事件。
- 能在低价值事件中保持沉默。
- 语音输出简洁自然。

后续阶段可以扩展多种解说风格，例如赛事正式风、轻松娱乐风、主播搭档风和高燃集锦风。
