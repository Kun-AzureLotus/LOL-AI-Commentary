# 产品愿景

## 项目名称

英雄联盟AI解说员。

## 产品定位

英雄联盟AI解说员是一款为《英雄联盟》实时对局生成专业电竞语音解说的开源软件。它的目标是让普通排位赛获得接近 LPL 或 LCK 直播的观赛氛围，而不是提升玩家胜率或指导玩家操作。

该项目的核心身份是 AI 电竞解说员。它不是 AI 教练，不是作弊工具，也不是自动化助手。

## 目标用户

第一类用户是正在自己打排位的玩家。他们希望在不被操作建议打扰的情况下，获得更有沉浸感的比赛氛围。

第二类用户是主播或内容创作者。他们希望为直播画面增加专业解说感，使普通对局更像赛事转播。

这两个场景共享同一条产品边界：系统只能基于玩家画面和玩家队伍合法可见的信息进行解说。

## 核心体验

产品应让玩家感觉自己正在经历一场被专业解说关注的比赛。AI 不应机械播报日志，而应理解比赛背景，判断事件重要性，并在合适的时机发声。

一次击杀本身可能并不重要。但如果这次击杀导致男爵、小龙魂、防御塔推进或比赛结束，AI 应解释它为什么重要。相反，如果事件价值很低、信息置信度不足，或玩家正在高强度操作，AI 应保持沉默。

理想体验包括：

- 对团战、一打一、资源争夺和推进结果进行专业解说。
- 根据比赛阶段和资源背景解释事件意义。
- 用情绪化但不越界的语言增强赛事氛围。
- 在低价值事件或玩家需要专注时主动留白。
- 只输出语音，不要求玩家阅读额外界面。

## 信息边界

系统只能使用两个来源的信息：

- Riot 实时客户端 API 提供的结构化游戏数据。
- OBS 捕获的玩家本人游戏画面。

OBS 只捕获玩家自己的画面，包括小地图、镜头位置、技能动画、英雄移动、视觉特效和玩家视角。系统不得结合隐藏状态推断战争迷雾内敌人位置，也不得预测未来事件。

所有输入必须经过可见性过滤和状态融合，才能进入后续事件识别、游戏状态解释和解说生成流程。

## 非目标范围

本项目明确不做以下事情：

- 不提供操作建议。
- 不回答“我该做什么”类问题。
- 不预测敌方隐藏位置。
- 不根据不可见信息推断未来事件。
- 不自动接受对局、自动选人、自动禁用、自动符文或自动聊天。
- 不做战绩侦察或识别“谁是突破口”的辅助判断。
- 不复制任何参考仓库的具体实现。

## 成功标准

项目成功的标准不是 AI 是否能说很多话，而是它是否能在正确的时机说正确的话。

短期成功标准：

- 能稳定采集 Riot API 和 OBS 玩家画面信息。
- 能识别基础事件，如击杀、资源获取、团战结果和防御塔变化。
- 能避免输出操作建议和隐藏信息推断。
- 能在明显高价值事件中生成自然、专业的语音解说。

长期成功标准：

- 解说具备持续叙事感，而不是孤立事件播报。
- 事件重要性判断足够可靠。
- 沉默策略能减少噪音。
- 开源社区可以审计信息边界和安全约束。
- 架构支持不同模型、TTS 和视觉识别方案的替换。

## 产品原则

- 合法可见信息优先于解说效果。
- 沉默优于低质量或越界发言。
- 事实判断应在结构化模块中完成，LLM 负责表达。
- 解说可以有情绪，但不能变成教练。
- MVP 应尽量小，优先验证实时性、信息边界和解说质量。
