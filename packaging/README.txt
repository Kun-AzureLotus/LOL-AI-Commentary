LOL AI Commentary — Portable Release

1. Requirements

Windows 10 / 11


2. First Start

Double click:

Launcher.exe


3. Configure

Open Settings and configure:

- API Provider
- API URL
- Model
- API Key
- Voice
- Commentary Language

Enter the API Key in Settings. Do not put a real key in this folder or in any file next to Launcher.exe unless you choose to use a local .env yourself.


4. Start

Return to Home and click Start Commentary.


5. OBS

OBS is optional when you only want to open the Launcher.

For full visual information during commentary, start OBS first and configure the WebSocket source if needed.


6. League of Legends

Enter a game, then start Commentary.

The Launcher can open without League of Legends running.


Notes

- launcher.json is created next to Launcher.exe after you save settings.
- API keys are not stored in launcher.json. Configure them in Settings.
- Windows Speech voices are used for TTS. Install a voice in Windows if the list is empty.
